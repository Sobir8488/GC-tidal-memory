# Scope and limitations

This archive contains curated machine-readable tables, selected authoritative
source artifacts, publication figures, and lightweight post-processing code.

It does not include the manuscript or journal source files.

Scientific scope:
- 24 tested cluster-potential groups are classified as robust material chaos.
- 12 Irrgang13III confirmatory endpoints have full functional stability.
- 12 McMillan17 confirmatory endpoints remain functionally unresolved.
- These counts describe the frozen tested matrix and are not population
  prevalence estimates.
- No McMillan17 combined endpoint is defined.
- A chaos label does not rescue a failed functional-convergence result.
- Observational covariance is characterized but was not propagated through
  the full confirmatory orbit/tensor/Lyapunov calculation.

The archived old T6_LYAPUNOV_CHAOS_RAW_V1_0_3 namespace is intentionally
excluded because it is not the final cluster-specific authority. Final chaos
tables and figures derive from the authoritative 96-row classification product.
